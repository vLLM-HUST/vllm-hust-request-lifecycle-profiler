# Results

Do not commit raw or intermediate experiment outputs here. Canonical evidence
belongs in vllm-hust-benchmark; see [the verified input roots](../../../EVIDENCE.md).

The template's generic `make paper-assets` path scans this directory,
generates a manifest and Markdown summary, stages any figure-like files into
`figures/generated/`, and emits a LaTeX summary snippet under
`tables/generated/`.

The example metrics are template fixtures, not measurements. Historical paper
projections already tracked here remain pending separate byte-preserving custody
and consumer migration; they are not canonical inputs or permission to add data.
New `paper_assets_latest/`, generated tables and figures are ignored build outputs.
Publish experimental derivatives to benchmark with their source bindings.
